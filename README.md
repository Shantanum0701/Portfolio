# Personal Portfolio

A modern, minimalist personal portfolio website designed to showcase projects and skills. Built with a focus on clean typography, responsive layout, and performance using vanilla web technologies.

## 🚀 Live Demo
[View Portfolio](https://shantanum0701.github.io/Portfolio/)  
*(Ensure GitHub Pages is enabled in your repository settings)*

## ✨ Features

- **Modern UI/UX**: Clean dark theme with electric blue accents.
- **Responsive Design**: Fully responsive layout that works on all devices (Desktop, Tablet, Mobile).
- **Project Showcase**: Detailed project cards with technology tags and descriptions.
- **Interactive Elements**: Smooth scrolling, fade-in animations, and hover effects.
- **Contact Integration**: Direct mailto links and social media integration.
- **Resume Integration**: Direct Google Drive view/download support.

## 🛠️ Technologies Used

- **HTML5**: Semantic markup for accessibility and structure.
- **CSS3**: Custom properties (variables), Flexbox, and CSS Grid for layout.
- **JavaScript (ES6+)**: Vanilla JS for animations and dynamic year updates.
- **Fonts**: 'Space Grotesk' for headings and 'Inter' for body text (via Google Fonts).

## 📂 Project Structure

```

```

1. Clone the repository:
